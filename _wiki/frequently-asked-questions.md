These are some of the questions we get often on the <a href="/wiki/">Redstoneworld</a>. Hopefully this guide helps you out.

## Will there be / is there a world download? {#will-there-be-is-there-a-world-download}
Unfortunately, no world download is currently available. It will be available once all the current work in progress sectors will be completed. It will be available for 1.20.4 Java only. However, the world is still open to be explored by any player by joining the server on the IP listed. Besides joining the world, you can also see a preview of our progress online by visiting our dynmap at <a href="http://map.theredstoneworld.net:7777">http://map.theredstoneworld.net:7777</a>

## What is the Server IP? {#what-is-the-server-ip}
The server IP is <code>mc.theredstoneworld.net -</code> The server runs on 1.20.4 Java, but is able to host versions 1.7 and later (however, versions after 1.18 are strongly recommended).

### Does Bedrock Edition work? {#does-bedrock-edition-work}
Yes, actually! The IP and port for bedrock edition is <code>bedrock.theredstoneworld.net:19132</code>. If Geyser is out of date, contact Ij. Also, if you are joining from Bedrock Edition and notice your username does not start with an _ (underscore), then rejoin the server. This is unfortunately a Geyser bug.

## Can I join staff? {#can-i-join-staff}
Yes, staff applications are open. The easiest way to get into staff is to join the <a href="https://discord.gg/G4UYpxy">Discord Server</a> and use the <a href="https://forms.gle/4DfGiq4jvLSDFSFN6">Google Form</a> link to submit an application. Before filling out the application, make sure that you have at least 5 hours of playtime in the server and spent some time getting yourself familiar with Mainworld. Once that is done, the Coalition will check your application. If it is moved into stage 2, you can either choose to apply as a redstoner or as a builder. Typically, the builder path is easier for most people, as the redstoner path includes a relatively difficult test. The build test constitutes of building a log cabin with a fully decorated interior and exterior. The build test should represent your build ability fairly well and shouldn't take more than a couple hours to make. You, however, can take as much time as you want. About 2 days after the build is submitted, the Coalition will either make a decision to accept or deny you from the build team.
